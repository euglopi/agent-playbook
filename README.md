# Agent Playbook

Practical guides for getting useful, verifiable work from AI coding agents.

Start with a clear outcome, give the agent room to solve the problem, and judge the result by what works. This collection turns that approach into short guides you can adapt to your own projects.

## Start here

| When you need to… | Read |
| --- | --- |
| Give an agent a task it can finish without guessing your intent | [Write a clear task brief](guides/task-brief.md) |
| Decide whether a change is ready to use | [Verify the result](guides/verify-the-result.md) |

These are guides to read and adapt, not an installer or a complete tool setup. Copy a brief into your coding assistant, fill in the project details, and keep the permissions and limits specific to the task.

## The working principles

- Describe the result a person needs, not just the file to edit.
- Let the agent decide routine implementation details within the agreed scope.
- Keep product choices, spending and access boundaries explicit.
- Test the path a person will actually use, including failures and recovery.
- Keep evidence of what works and say plainly what remains unknown.
- Save useful lessons where the next task will find them.

## Suggest an improvement

[Open an issue](https://github.com/euglopi/agent-playbook/issues) with the guide, the situation where it fell short, and a concrete example. Remove private project details before sharing. Proposed edits are welcome through pull requests.

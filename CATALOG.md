# Skills and guides

Skills are repeatable instructions for an AI agent. Each local skill includes the supporting references it needs. Guides are reference material to read alongside the task.

## Skills in this collection

| Skill | What it does |
| --- | --- |
| [context-audit](skills/context-audit/SKILL.md) | Find which instructions load into an agent session, how much space they use, and where they conflict. |
| [design-audit](skills/design-audit/SKILL.md) | Review a working interface for accessibility, keyboard use, layout and interaction problems. |
| [git-branching-quiz](skills/git-branching-quiz/SKILL.md) | Learn branches, worktrees, releases and hotfixes through a short interactive quiz. |
| [loop-audit](skills/loop-audit/SKILL.md) | Find bugs, loose ends, stale docs and reusable lessons without changing anything. |
| [loop-run](skills/loop-run/SKILL.md) | Find and fix useful follow-ups within the current task and its permissions. |
| [model-effort](skills/model-effort/SKILL.md) | Choose the work method, model, reasoning level and use of helpers from evidence. |
| [presentation-rules](skills/presentation-rules/SKILL.md) | Shape a report, plan or deck around its reader’s goal and approved brand inputs. |
| [report-rules](skills/report-rules/SKILL.md) | Build readable reports with clear evidence, honest totals and numbers that do not wrap. |
| [social-post](skills/social-post/SKILL.md) | Draft concise posts about a build, its failure, its fix and the lesson it supports. |
| [systematic-debugging](skills/systematic-debugging/SKILL.md) | Find and reproduce the cause of a bug before choosing a fix. |
| [task-observer](skills/task-observer/SKILL.md) | Turn recurring workflow problems into specific improvements to skills and rules. |
| [worktree-triage](skills/worktree-triage/SKILL.md) | Work out which local working folders hold unfinished work and which can safely be retired. |

The presentation and report skills are portable editions: supply your own approved brand inputs. The social-post skill is a chosen writing style, not a rule for every author. Model and platform guides keep their source dates; confirm changing controls and limits before use.

## Material not redistributed

The synced `docs`, `google-workspace`, `morning` and `import-memory` copies have no established redistribution permission in this review. They are not included as downloadable skills. For memory import, see [Claude’s official product instructions](https://support.claude.com/en/articles/12123587-import-and-export-your-memory-from-claude).

Project-specific production runbooks, brand assets, account settings, private notes and historical working records are outside this collection. They are not prerequisites for the portable skill editions above.
